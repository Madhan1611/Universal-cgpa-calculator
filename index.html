Bulk student result workflow

Upload results, import the credit master separately, review extracted rows, then calculate each student's semester GPA and CGPA.

Step 1 — Upload student result files

Supported: Excel, CSV, PDF, DOCX, TXT and images. For reliable extraction, use a clear table with Register Number, Student Name, Semester, Subject Code, Subject Name and Grade. You may select multiple files.

Step 2 — Import subject codes, names and credits

Upload the credit master separately. Required columns: Subject Code, Subject Name, Credits. The same subject code reuses the imported credit value. Unmatched codes remain flagged; no credits are guessed.

Step 3 — Review and edit extracted records

You can edit register number, name, semester, code, subject, grade and credits before calculation.

Grade & Class Settings

Grading scale

Edit these values to match your institution's official rules. Grades such as RA/U/F are treated as zero only if listed here; whether they should count toward credits is institution-specific.

Local data

Data is stored in this browser using localStorage. It does not automatically sync to another device or browser. Export reviewed CSV files for backup.

How it works

GPA formula

GPA = Σ(grade points × subject credits) ÷ Σ(subject credits).

CGPA formula

CGPA = Σ(semester GPA × eligible semester credits) ÷ Σ(eligible semester credits). The class analysis calculates cumulative values using the included subject rows and their credits.

Data extraction

File extraction is best-effort. OCR and PDF/Word extraction can misread scanned or complex layouts. The extracted rows are editable so that you can verify them before calculation.

Privacy

Data stays in local browser storage unless you manually export/share files. Clearing browser site data may remove it. Keep your own backup.

Credit rules

Subject credits are matched by subject code from the separately imported credit master. Missing codes, grades, semesters or credits are flagged; they are never silently invented.
