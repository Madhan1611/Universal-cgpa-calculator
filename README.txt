UNIVERSAL GPA AND CGPA CALCULATOR — UPDATED FILES

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser. Excel/PDF/Word/image reading libraries load from CDNs, so an internet connection is needed for those formats.
3. In Class Analysis, upload student results first.
4. Separately import the subject-credit master (Subject Code, Subject Name, Credits).
5. Review and edit extracted records, match credits, and calculate class results.
6. Export reviewed data/summary as CSV for backup.

Important:
- Extraction from PDF, Word, or photos is best-effort; review every row.
- The calculator flags missing/invalid data and does not invent credits or grade points.
- Browser localStorage is local to that browser/device. Clearing site data can erase saved data.
- Set grade points to your institution's official rules before relying on results.
